# Operation & Usage Manual - Antigravity Universal AI Provider (`ag-provider`)

> [!IMPORTANT]
> **FATOS CRÍTICOS DE ARQUITETURA (MODO DUPLO DE OPERAÇÃO)**:
> 1. **Modo Proxy Universal (`ag-provider`) vs. Modo Nativo Oficial Gemini**:
>    - **Para usar o Proxy Universal (`ag-provider`)**: Inicie o Antigravity IDE via terminal PowerShell definindo `$env:CLOUD_CODE_ENDPOINT = "http://127.0.0.1:50051"`. 100% do tráfego do chat será redirecionado para a porta `50051`. O modelo ativo é escolhido dinamicamente no **Web Control Dashboard (`http://127.0.0.1:50051/dashboard`)**. O Google recebe 0 bytes e a cota do Google é 0% consumida!
>    - **Para usar o Gemini Oficial**: Abra a IDE normalmente pelo seu atalho do Windows (Menu Iniciar / Área de Trabalho) sem passar a variável no terminal. A IDE conversará direto com a nuvem da Google.
> 2. **Seletor de Modelos na Interface da IDE**:
>    - No Modo Proxy, o menu suspenso dentro da IDE (ex: *Gemini 3.6 Flash*) é **meramente um rótulo visual estático**. A IA que responde de verdade é a que está ativada no Web Dashboard!

## 1. Understanding the Architecture & Google Login Requirement

### ❓ Why does Antigravity IDE ask for a Google Login?

Antigravity IDE (built on an Electron/VS Code foundation) requires a Google account login **solely to unlock the UI chat drawer and assistant panel**. 

### 🔀 How Traffic Rerouting Works (`ag-provider`)

When you set `"antigravity.agentHostAddress": "http://127.0.0.1:50051"` or launch the IDE with `$env:CLOUD_CODE_ENDPOINT = "http://127.0.0.1:50051"`:

1. **All ConnectRPC AI Requests** generated by the IDE are redirected locally to `127.0.0.1:50051`.
2. **Zero Traffic Goes to Google's Cloud AI Companion**: The local `ag-provider` proxy intercepts 100% of LLM inference calls.
3. **Frontend Selector vs. Real Model**:
   - The model dropdown **inside Antigravity IDE UI** (e.g. *Gemini 3.6 Flash*) acts as a visual frontend label.
   - The **actual LLM backend** that processes and responds to your prompt is determined by the active provider selected in the **Web Dashboard (`http://127.0.0.1:50051/dashboard`)**.

```
+---------------------+          ConnectRPC Protobuf         +---------------------+
|   Antigravity IDE   |  --------------------------------->  |     ag-provider     |
| (Requires UI Login) |   http://127.0.0.1:50051             | (Local Proxy Bridge)|
+---------------------+                                      +---------------------+
                                                                        |
                                                                        | OpenAI REST / SSE
                                                                        v
                                                             +---------------------+
                                                             | Target Provider     |
                                                             | (Kimi / Groq / Qwen |
                                                             | OpenRouter / Ollama)|
                                                             +---------------------+
```

## 2. Security & API Key Isolation (`.env` vs GitHub)

> [!CAUTION]
> **NEVER COMMIT SENSITIVE API KEYS TO PUBLIC GITHUB REPOSITORIES!**

To ensure absolute security, `ag-provider` utilizes a 2-tier configuration model:

1. **Public File (`src/ag-provider/providers.json`)**: Contains public endpoint definitions and environment variable placeholders (e.g. `${KIMI_API_KEY}`, `${GROQ_API_KEY}`). This file **IS** tracked in Git.
2. **Secret File (`src/ag-provider/.env`)**: Contains your real, private API keys. This file **IS NOT** tracked in Git (explicitly ignored by `.gitignore`).

## 6. Launching the Proxy Server & Dashboard

Start `ag-provider`:

```powershell
cd E:\00Dev\AntigravityUnlock\src\ag-provider
npm start
```

Upon startup, `ag-provider` automatically loads `.env` and starts listening on port `50051`:

```
=======================================================
  Antigravity Universal AI Provider Bridge (ag-provider) 
  Control Panel: http://127.0.0.1:50051/dashboard
  Running on http://127.0.0.1:50051
=======================================================
```

Open **`http://127.0.0.1:50051/dashboard`** in your web browser to view active metrics, switch models dynamically, and test connection latency.

## 7. Configuring and Launching Antigravity IDE

Execute the following PowerShell commands to launch Antigravity IDE pointing to your local proxy:

```powershell
# Set environment variables for ConnectRPC host redirection
$env:CLOUD_CODE_ENDPOINT = "http://127.0.0.1:50051"
$env:CODEIUM_CLOUD_CODE_ENDPOINT = "http://127.0.0.1:50051"

# Launch Antigravity IDE
Start-Process "$env:LOCALAPPDATA\Programs\Antigravity IDE\Antigravity IDE.exe" -ArgumentList "--user-data-dir=`"E:\00Dev\AntigravityUnlock\.test-ide-profile`"","--new-window"
```

Or add the setting directly to your IDE `settings.json`:
```json
"antigravity.agentHostAddress": "http://127.0.0.1:50051"
```

## 9. Troubleshooting & Diagnostics

### Issue: `ERR_CONNECTION_REFUSED` on port 50051
- **Cause**: The `ag-provider` server process is not running.
- **Fix**: Run `npm start` inside `src/ag-provider`.

### Issue: Provider returns 401 Unauthorized
- **Cause**: Invalid API key inside `src/ag-provider/.env`.
- **Fix**: Double check your key in `.env` and restart `ag-provider`.

### Issue: Dashboard dropdown does not show new providers
- **Fix**: Refresh the browser page (`F5`) to trigger dynamic provider fetching from `/api/status`.
